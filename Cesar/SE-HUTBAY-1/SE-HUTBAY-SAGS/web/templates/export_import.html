Export / Import

Exporta bloques de configuracion a un JSON y restauralos en otro entorno. El archivo guarda la fecha y que casillas estaban marcadas.

El motor SE esta corriendo. Detenlo en Configuracion SE antes de importar.
1 Exportar

Marca los bloques que quieres incluir y guarda un archivo JSON en tu PC.

El archivo lleva la configuracion de ese SAG.
2 Importar

Abre un JSON exportado desde esta pagina. Solo se aceptan archivos con formato se-hutbay-export.

SAG que se queda con los setpoints, el handshake y el heartbeat del archivo. Los demas los leen.
