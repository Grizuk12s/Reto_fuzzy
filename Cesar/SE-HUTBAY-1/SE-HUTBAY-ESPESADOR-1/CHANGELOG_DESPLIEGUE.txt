================================================================================
  8. PROBLEMAS ENCONTRADOS Y COMO SE RESOLVIERON
================================================================================

  P1  scp -r root@... "Permission denied"
      Causa: SSH del Ubuntu no acepta login de root por password.
      Fix:  scp -r ... operador@192.168.137.94:/tmp/  y despues, ya como
            root en la VM, mv /tmp/Test-conexion-Entornos /root/Test/

  P2  Estructura anidada tras el scp
      Causa: scp -r "Test-conexion-Entornos" host:/tmp/ crea /tmp/Test-conexion-Entornos/
             y el mv a /root/Test/ (que ya existia) genero /root/Test/Test-conexion-Entornos/Test-conexion-Entornos/
      Fix:  cd /root/Test
            mv Test-conexion-Entornos Test-conexion-Entornos.tmp
            mv Test-conexion-Entornos.tmp/Test-conexion-Entornos .
            rmdir Test-conexion-Entornos.tmp

  P3  unzip no disponible en Linux
      Causa: Ubuntu server minimal, sin unzip, sin internet.
      Fix:  Transferir la carpeta sin comprimir (scp -r) en lugar de .zip.

  P4  KEPserver "Connection refused" desde la UI
      Causa: se puso la IP corporativa 10.0.10.155 (no accesible desde VM).
      Fix:  usar 192.168.137.1 (NIC "Switch Planta").

  P5  KEPserver "BadSessionNotActivated"
      Causa: login anonimo deshabilitado en Settings -> OPC UA.
      Fix:  activar "Allow anonymous login" y reinicializar runtime.

  P6  Postgres "no pg_hba.conf entry"
      Causa: Postgres escuchando solo en localhost o pg_hba sin la subred.
      Fix:  listen_addresses='*' + host 192.168.137.0/24 en pg_hba, restart.
